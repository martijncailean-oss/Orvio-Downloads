# Orvio for Android and Android TV

[Download Orvio 0.04 APK](https://github.com/martijncailean-oss/Orvio-Downloads/releases/download/v0.04/Orvio-0.04.apk)

Install the APK manually once, then connect your IPTV source. Orvio 0.04 includes automatic app update downloads and IMDb / Rotten Tomatoes poster ratings.

## Automatic updates

- New versions download in the background over Wi-Fi or Ethernet by default.
- Use **Settings → Updates** to check manually, disable automatic downloads, or allow mobile data.
- When an update is ready, choose **Install update**. Android may ask you to allow installation from Orvio.
- You can choose **Later** and continue watching.

This repository hosts APK downloads and update metadata only. The app source repository remains private. This is a preview release.
