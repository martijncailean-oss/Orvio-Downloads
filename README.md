# Orvio for Android and Android TV

[Download Orvio 0.05 APK](https://github.com/martijncailean-oss/Orvio-Downloads/releases/download/v0.05/Orvio-0.05.apk)

Install the APK manually once, then connect your IPTV source. Orvio 0.05 adds an AC-3/E-AC-3 audio fallback, refreshed phone screens, landscape fullscreen and detailed download progress.

## Automatic updates

- New versions download in the background over Wi-Fi or Ethernet by default.
- On phones: **Settings → App updates**. On TV: **Settings → Updates**.
- When an update is ready, choose **Install update**. Android may ask you to allow installation from Orvio.
- You can choose **Later** and continue watching.

## Open-source audio components

[Complete audio-library sources, build scripts and licenses](https://github.com/martijncailean-oss/Orvio-Downloads/releases/download/v0.05/Orvio-audio-sources-0.05.zip).

This repository hosts APK downloads, update metadata and required third-party source bundles. The Orvio application source remains private. This is a preview release.
